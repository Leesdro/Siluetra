---
name: siluetra-debugging
description: Diagnose Siluetra failures with evidence.
---

REPRODUCE → TRACE → ROOT CAUSE → MINIMAL FIX → REGRESSION TEST → VERIFY. Use fictional fixtures. Trace interaction → command → model/document → geometry/render → browser result. Separate evidence from hypothesis. No speculative patches, fallback-condition chains, changing tests to hide failures, or browser-success claims based only on unit tests.
