# Paper.js geometry adapter (MIT)

`dist/vendor/paper-geometry.js` derives from Paper.js 0.12.18 `dist/paper-core.js`, release commit `c1d88390d2c86901db152827fe778c3e39cfb073`, https://github.com/paperjs/paper.js. Original copyright and license headers are retained; the full license and precise wrapper changes ship as `PAPER-LICENSE.txt` and `PAPER-NOTICE.txt`. Siluetra uses the floating-point curve boolean/intersection implementation through its native ESM adapter. The renderer, document model and garment semantics remain Siluetra's. Paper.js is not represented as an exact symbolic or certified geometry kernel.
